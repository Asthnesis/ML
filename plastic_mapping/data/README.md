# Data

Not tracked in git (see `.gitignore`) — this data is provided under the
Zindi/FAO GEO-AI competition terms and isn't redistributed here.

To reproduce, download the competition dataset from Zindi and place these
files in this folder:

```
Kenya_training.csv
Kenya_testing.csv
Spain_training.csv
Spain_validation.csv
VNM_training.csv
VNM_testing.csv
SampleSubmission.csv
VariableDefinitions.csv
```

`train.py` reads directly from these filenames.
